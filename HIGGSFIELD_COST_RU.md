# Стоимость Higgsfield

Перед отправкой новой задачи приложение запрашивает оценку `/estimate/{model endpoint}` с теми же параметрами и референсами. Цена и время оценки сохраняются в записи. Если сервис оценки недоступен или не вернул сумму, после явного подтверждения повышенной стоимости генерация отправляется без цены; в Cost запись остаётся без известной стоимости. Ошибки авторизации и неверных параметров по-прежнему останавливают запуск.

После успешной генерации оценка попадает в cost с costSource=api_estimate. Это оценка API для аккаунта, не подтверждённое списание. Если провайдер в дальнейшем вернёт фактический cost, он имеет приоритет. Ошибки и отмены с одной лишь предварительной оценкой не увеличивают расходы.

Cost объединяет провайдеров, показывает разбивку по API, пользователей и подробности каждого видео. Доступ к записям остаётся прежним: пользователь видит свои, суперадмин — команду.

Для старых записей без сохранённой цены отображается «цена не сохранена». Их нельзя достоверно восстановить из API статуса, который не документирует сумму списания; они не считаются бесплатными и отмечены в счётчике без цены. Калькулятор и редактируемый тариф BytePlus не применяются к Higgsfield.
