# Загрузка видеореференсов · 0.12.3

На сайте подключён отдельный сервис https://magic-video-upload.danmgcmgc.workers.dev . Он использует Workers Free и Workers KV, без R2 и без ключа BytePlus. Загрузка: MP4/MOV до 20 МБ; файл автоматически истекает через 6 часов. В Canvas выбери файл обычной кнопкой добавления медиа и нажми Generate. Первая отправка ждёт примерно 65 секунд после загрузки для распространения KV. Повторные генерации используют ссылку из памяти, пока она действительна.

Приватный namespace: magic-video-references. Binding: VIDEO_FILES. Источник сервиса: cloudflare-worker/kv-references.js, конфигурация отдельного деплоя: cloudflare-worker/wrangler-kv.toml. Это НЕ основной BytePlus Worker; существующие настройки Direct API и ключи не меняются. Адрес загрузки задан в source/firebase-config.js как referenceUploadUrl.

Бесплатные лимиты Cloudflare Workers KV: 1 ГБ хранения, 1000 записей и 100000 чтений в день; лимиты общие на аккаунт. На Workers Free при превышении операции завершаются ошибкой, а не переходят на оплату. Не включай Workers Paid или R2, если требуется строго бесплатная работа. Генерация BytePlus оплачивается отдельно.

https://developers.cloudflare.com/kv/platform/pricing/
https://developers.cloudflare.com/kv/platform/limits/

Загрузка требует Firebase ID token и профиль команды user/superuser. Ключ провайдера в сервис не передаётся. Ссылка содержит случайный непредсказуемый токен; прочитать файл может тот, у кого есть эта ссылка, в том числе AI-провайдер. В Firestore сохраняются только прежние метаданные, без байтов и временной ссылки.

KV распространяет новые данные между регионами не мгновенно; ожидание снижает вероятность временного 404, но не даёт гарантии мгновенной доступности при сбоях Cloudflare. В таком случае повтори отправку позднее. Поддержку кодека, разрешения и длительности определяет API модели. Рабочий ПК не нужен для доступа провайдера к уже загруженному файлу.

Ранее подготовленный вариант R2 в references.js остаётся опциональным для иных конфигураций и на этом аккаунте не активирован.
