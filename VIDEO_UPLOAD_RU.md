# Загрузка видеореференсов из файла · 0.12.2

В Canvas выбери MP4/MOV обычной кнопкой добавления медиа. При Generate сайт загрузит файл во временное хранилище Worker и отправит ссылку как video_url / reference_video. Поддерживаются файлы до 30 МБ. Локальный оригинал остаётся в браузере. В Firestore не записываются ни байты видео, ни временный токен ссылки. Повторные генерации используют ссылку из памяти, пока она действительна.

## Один раз настроить Cloudflare

1. Создай приватный R2 bucket `magic-reference-staging`. Публичный r2.dev доступ включать не нужно.
2. В bucket → Settings → Object lifecycle rules добавь удаление объектов с префиксом `reference-staging/` через 1 день. Это обязательно для ограничения накопления файлов; истечение ссылки само по себе не удаляет объект.
3. В существующем Worker → Settings → Bindings добавь R2 bucket binding: имя `REFERENCE_FILES`, bucket `magic-reference-staging`. Если уже есть `PORTRAIT_FILES`, код может использовать его, но правило lifecycle для `reference-staging/` всё равно нужно добавить.
4. Обнови модули Worker из папки `cloudflare-worker`, включая новый `references.js`. При деплое Wrangler сохрани существующие vars, secrets и bindings; пример нового binding закомментирован в `wrangler.toml`, его нужно включить с реальным именем bucket. Не заменяй секреты ключами из исходников.
5. В My settings сайта должен быть указан URL этого Worker. При режиме Direct API можно сохранить Worker URL BytePlus для загрузки исходников; генерация OpenRouter также может использовать его хранилище.

Файл доступен по подписанной ссылке 24 часа: её может прочитать тот, кто её получил, включая выбранного AI-провайдера. Bucket остаётся приватным. Загрузка требует действующей авторизации участника команды. Для MP4/MOV проверяются MIME, сигнатура контейнера и размер; соответствие кодека, длительности и разрешения требованиям модели проверяет провайдер.

У R2 есть бесплатные месячные лимиты, превышение оплачивается: https://developers.cloudflare.com/r2/pricing/ . Само создание видео в Seedance платное. Настройки Firebase менять не нужно.

Если старый Worker отвечает Not found или хранилище не настроено, генерация не отправляется, сайт показывает причину. Публикация GitHub Pages не обновляет Cloudflare Worker автоматически.
