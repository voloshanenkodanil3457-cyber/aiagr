# Dashboard и расчёт Higgsfield

Последние генерации показывают ник из профиля, короткое название, дату, статус и цену. Названия из 2–3 слов создаёт Cloudflare Workers AI: до 6 промптов за запрос, кэш в браузере с привязкой к пользователю и тексту промпта. При недоступности ИИ показывается нейтральная подпись, без платного резервного провайдера. Это не запускает видео.

График и сводка над ним относятся к последним семи календарным дням; верхние счётчики — ко всей доступной истории. Наведение, фокус или нажатие на столбик показывают таблицу с ником, количеством генераций и стоимостью. Доступ к данным остаётся прежним: пользователь видит свои записи, суперадмин — команду.

Калькулятор Higgsfield считает `ceil(width × height × 24 × (input_seconds + output_seconds) / 1024)` видеотокенов. За 1000 токенов: Seedance 2.0 — $0.014, Seedance 2.5 — $0.0214 при 480p/720p и $0.0234 при 1080p. С видеовходом ставка умножается на 0.6; учитываются длительности и входа, и результата. Изображения не добавляют видеосекунды. Пользователь явно указывает свою скидку; по умолчанию 0%, не предполагается неизвестная скидка аккаунта.

Официальные тарифы проверены 24.10.2026:
- https://open.higgsfield.ai/models/bytedance/seedance-2.0/reference-to-video/playground
- https://open.higgsfield.ai/models/bytedance/seedance-2.5/reference-to-video/playground

Сохранённый API cost имеет приоритет, затем API-оценка, затем публичный расчёт при достаточных данных. Оценки помечены ≈ и входят в общие итоги. Для новых успешных задач публичная оценка фиксируется с версией `hf-public-tokens-2026-10-24`. Если длительность входного видео неизвестна, цена остаётся неизвестной. Она не считается нулём. Неудачные задачи с одной лишь предварительной оценкой не увеличивают расходы. Расчёт не подтверждает списание с баланса.
