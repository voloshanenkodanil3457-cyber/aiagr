# Magic 0.8.3

Кнопка «Скачать видео» для BytePlus сразу открывает исходную ссылку для сохранения. Промежуточное окно «Сохранить видео» удалено. Предварительный просмотр и запрос fetch к CDN не нужны.

Изменение общее для Assets, ноды Output и предпросмотра. Кнопка в ноде остаётся под плеером. Проверка доступа к собственным генерациям и прав суперадмина сохранена. OpenRouter использует прежний механизм скачивания.

Обновлять Firebase rules или Cloudflare Worker не требуется.
