# Запуск с референсами — Magic 0.7.4

## Что было видно на скриншотах

1. Локальное видео `video_3d_base.mp4` остановлено проверкой референсов: видео
   требует публичной HTTPS-ссылки. Предыдущая ошибка Safe Experience Mode в Output
   относится к прежнему запуску. Локальный preview не является ссылкой для BytePlus.
2. При фото кнопка `Generating…` и надпись `Ready to generate` не объясняли,
   ожидается ли чтение изображения, ответ API или подтверждение задачи.
   По скриншоту нельзя установить точную причину задержки сети.

## Исправления

- `source/canvas.js`: подготовка, отправка и генерация отображаются отдельно.
  До получения ID задачи Output показывает ожидание ответа, а не готовность.
- `source/app.js`: запросы Direct и Worker ограничены 90 секундами, включая
  чтение JSON-ответа. При таймауте кнопка освобождается, выводится реальная ошибка.
- Чтение файла и получение локальной копии также имеют ограничение ожидания.
- Таймаут POST означает `submission_unknown`: провайдер мог принять задачу.
  Автоматического повторного POST нет; проверь историю BytePlus перед повторением.
- Диагностический `request_id` больше не принимается за ID созданной задачи.
- Ошибка 429 Safe Experience Mode сопровождается подсказкой о лимите BytePlus.
  Увеличение/отключение лимита делается в аккаунте провайдера, а не в коде.
- Готовый результат или ошибка сразу сохраняются локально и появляются в Output.
  Запись отчёта в Firestore идёт в фоне: недоступная база не блокирует интерфейс.
  Если запись не завершилась, локальная очередь повторяет её при следующем входе.
- Корневые HTML пересобраны: GitHub Pages использует именно их.

Фото передаётся в API как Base64; его байты не сохраняются в Firestore.
Для видео нажми **По ссылке** и вставь публичный HTTPS-адрес самого MP4/MOV,
доступный без входа в аккаунт. Ссылка на страницу просмотра не подходит.
Автоматическая загрузка локальных видео к внешнему хостингу в этой версии не добавлена.
Firebase остаётся на Spark, Firebase Storage не используется.

## Установка

1. Скопируй содержимое `aiagr-main` из архива в папку проекта с заменой файлов.
2. В терминале VS Code:

```powershell
git add .
git commit -m "Fix reference generation states and timeouts"
git push
```

3. Дождись успешной публикации Pages, затем обнови сайт через Ctrl+F5.

## Проверки

```sh
node --test tests/domain.test.cjs tests/worker.test.mjs
npm run test:browser
```

Браузерные проверки подменяют BytePlus и Firebase: платные запросы не выполняются.
Проверяются фактический запуск с фото, ожидание ID, таймаут подключения и JSON,
Direct/Worker, отсутствие повторного POST, локальное видео и ошибка лимита.

Документация: https://docs.byteplus.com/en/docs/modelark/create-video-generation-task-api
