# Magic 0.8.5 — Cost и тарифы в USD

Winners переименован в Cost. Новый адрес cost.html; старый winners.html показывает тот же раздел. Калькулятор, карточки Assets и Dashboard показывают доллары вместо очков. Суперадмин видит стоимость сохранённых генераций команды, обычный пользователь — своих.

Начальные ставки за секунду: 480p — $0.103, 720p — $0.231, 1080p — $0.569. Стоимость = секунды × ставка. Например, 4 секунды 480p — $0.412, 15 секунд 720p — $3.465. Это расчётная стоимость по предоставленному тарифу для запросов без видео-референса; сообщения API с фактической стоимостью имеют приоритет. Отдельный тариф для видео-референсов не задан: такие результаты без стоимости API отмечаются как неизвестная стоимость. Изображения не умножают цену.

В калькуляторе суперадмин может менять ставки. Изменение полей показывает предварительный расчёт. Сохранение требует отдельного подтверждения с предыдущими и новыми ценами. Обычный пользователь не может сохранять тарифы. При конкурентном изменении другим суперадмином сохранение отклоняется: нужно обновить страницу и подтвердить актуальные ставки.

Тарифы хранятся в config/videoPricing. Снимок ставок сохраняется при запуске каждой новой генерации, сумма — при завершении. Изменение ставок не меняет записанные суммы. Старые результаты без стоимости и без снимка ставок отображаются по начальным ставкам; новые ставки не меняют их расчёт. Удалённые из базы записи не входят в текущий отчёт расходов. Внутренний прежний учёт leaderboard остаётся совместимым с существующими правилами сохранения результатов и больше не показывается как XP.

## Firebase

Опубликуйте полный firestore.rules этого обновления в Firebase → Firestore Database → Rules. Новое правило разрешает участникам команды читать только публичный документ тарифов и разрешает менять его только суперадмину с проверкой структуры и положительных ставок. Остальные config-документы доступны только суперадмину. Публикация GitHub Pages не обновляет Firebase rules.

Cloudflare Worker и Storage rules менять не нужно. После публикации обновите сайт через Ctrl+F5. Для изменения тарифа откройте Cost, введите новые ставки и нажмите «Подтвердить и сохранить тарифы».
