# Подготовка будущего ZIP

Импорт ZIP пока не включён; этот формат нужен для следующей загрузки после получения архива.

Каждый аватар имеет постоянный служебный ID, например HU_M_001. Этот ID не показывается на карточке, но используется для сопоставления файла и описания. Пример структуры:

HU/HU_M_001.webp
HU/HU_M_001.md
PT/PT_F_001.webp
PT/PT_F_001.md

Пример MD:

---
id: HU_M_001
name: Adam
geo: HU
gender: male
age: 30
---

Короткие тёмные волосы, аккуратная борода, чёрная футболка.

GEO — рынок/папка, не определение национальности по фото. Если возраст неизвестен, поле age не заполняется. gender: male или female. Файлы JPG, PNG, WebP до 8 МБ. Описание до 500 символов. Одинаковые ID при будущем импорте должны проходить проверку на дубликаты до загрузки, а не создавать второй аватар молча.

MD используется только как текст описания. Инструкции, скрипты и команды из MD не исполняются.
