# Улучшение промпта

Кнопка «Улучшить промпт» в панели Canvas переписывает только текст. Видео она не запускает. Отмена изменения — Ctrl+Z.

В сервер включены 10 документов из предоставленных ZIP и RTF. Оригиналы после преобразования в текст находятся в cloudflare-worker/prompt-skills/. Файл prompt-skills.js содержит их индекс. По выбранной модели берётся основной документ для 2.0 или 2.5 и подходящие выдержки из остальных разделов. Это инструкции при запросе, а не переобучение модели.

Обработка выполняется через Cloudflare Workers AI, модель @cf/qwen/qwen3-30b-a3b-fp8. Для существующего Worker добавлена привязка AI. Новый API-ключ не нужен. В модель передаются текст, настройки и названия референсов; изображения и видео не загружаются для анализа.

На Workers Free доступна общая квота 10 000 neurons в сутки на аккаунт; после исчерпания запросы завершаются ошибкой. Платный план и AI Gateway credits для этой функции не подключаются. Квота сбрасывается в 00:00 UTC. Если владелец впоследствии самостоятельно перейдёт на Paid, нужно заново проверить условия оплаты.

При ошибке или изменении промпта во время обработки исходный/текущий текст сохраняется. Запросы требуют входа в Firebase и профиля команды. Платные видеопровайдеры не вызываются.
