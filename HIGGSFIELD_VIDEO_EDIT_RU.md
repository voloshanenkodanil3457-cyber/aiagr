# Редактирование Higgsfield Seedance 2.5

Для Seedance 2.5 с видеореференсом режим «Авто» или «Редактировать видео» использует `bytedance/seedance-2.5/video-edit`. Первый видеофайл передаётся как `video_url`, изображения — как `image_urls`, остальные видео — как дополнительные `video_urls`. Длительность и aspect_ratio не отправляются: режим сохраняет параметры исходного видео. Это показано перед подтверждением платного запуска.

«Новое видео» явно использует `reference-to-video` с выбранными длиной и форматом. Seedance 2.0 сохраняет прежнюю маршрутизацию. Продление через Higgsfield пока недоступно.

Сервер возвращает исходное поле `error` для неудачных задач, с удалением секретов и URL из сообщения. Отмена, ошибка обработки и модерация имеют разные запасные сообщения. В ответ статуса включён requestId для диагностики.

Проверка существующей задачи без новой генерации: `node scripts/higgsfield-status.mjs REQUEST_ID`. Ключ загружается только во время выполнения из игнорируемого `.env.local` и не печатается. Скрипт делает только GET статуса.
