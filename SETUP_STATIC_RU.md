# Запуск и следующий этап

Полное описание версии, прав и сохранения — в README.md.

Сейчас подготовлены только файлы. Ничего не опубликовано в Firebase, Cloudflare или на хостинге.

1. Распаковать проект. Готовые HTML уже собраны.
2. Запустить `python -m http.server 8000` из папки проекта и открыть `http://localhost:8000`.
3. В следующем этапе назначить своему существующему `users/{UID}` роль `superuser` и опубликовать `firestore.rules`. Назначение требует доступа владельца проекта в Firebase Console; код не повышает роль самостоятельно.
Firebase остаётся на Spark; Storage не требуется.

4. Если используется Cloudflare Worker — следовать `cloudflare-worker/README_RU.md` и обновить его до приглашения участников.
5. Проверить вход, собственный Space и одну генерацию. Затем создать пользователя в Users и проверить разделение Assets / отчётов.

После изменения source-файлов: `python source/build.py`. Если старый `saved-values.html` остался после копирования поверх предыдущей версии, удалить его вручную.
