# Magic 0.9.1 — исправление языка Captions

В Transformers.js 3.7.2 у Whisper не реализовано автоматическое определение языка: если language не передан, библиотека выбирает английский. В 0.9.0 кнопка «Авто» ошибочно полагалась на это поведение. Ручной выбор языка передавался явно.

В режиме «Авто» теперь выполняется отдельное локальное определение языка: Whisper получает аудиофрагмент и предсказывает один языковой токен с ограничением только на поддерживаемые языки. После этого выбранный код явно передаётся в распознавание с task=transcribe. Перевод на английский не запускается. Язык определяется для каждого ролика заново, без переноса результата предыдущего файла. При неуверенном определении предлагается выбрать язык вручную, без скрытой подстановки английского.

Страница показывает определённый или выбранный язык. При загрузке следующего видео результат прошлого определения очищается. Ручные EN / ES / PT / RO / HU / DE / FR / IT / PL / UK / RU остаются доступны; выбор языка не запускает перевод. URL Worker обновлён с версией, чтобы браузер не использовал прежний скрипт.

Проверки: реальное распознавание публичного французского примера в режиме «Авто» вернуло fr и французский текст. Следующий английский пример на той же модели вернул en и английский текст. Добавлены тесты отдельного определения, ручного выбора, смены ролика, неуверенного результата и обработки начальной тишины. Сохранены тесты таймкодов и экспорта.

Обновление: Ctrl+F5 на странице Captions, выбрать видео и нажать «Распознать речь» заново. Старые локальные черновики намеренно не заменяются автоматически. Для короткой, шумной речи или ошибки определения можно выбрать язык вручную.

Firebase, Worker-сервер и ключи API не нужны; обработка по-прежнему выполняется в браузере пользователя бесплатно.
