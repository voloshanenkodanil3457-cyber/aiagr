# Magic 0.8.2 — скачивание и кнопка Output

Кнопка «Скачать видео» в Output теперь находится отдельной строкой под плеером и не перекрывает таймлайн. Пока выполняется загрузка, повторное нажатие блокируется.

Общий механизм скачивания используется в Output, Assets и обоих предпросмотрах. Для BytePlus с настроенным доверенным Worker и подтверждением задачи файл запрашивается через уже существующий защищённый маршрут `/byteplus/media/{taskId}`, а не через CDN, который может запрещать браузерный fetch. Для OpenRouter Direct используется загруженный с авторизацией Blob; для Worker — подписанная ссылка. Открывать предпросмотр перед скачиванием не требуется.

Если прямая видеоссылка запрещает fetch через CORS и защищённая загрузка недоступна, сайт показывает окно с кнопкой «Открыть видео для сохранения». На открывшейся странице используй меню плеера ⋮ → Скачать или Ctrl+S. Это ограничение сервера: атрибут download сам по себе не гарантирует скачивание сторонней ссылки. Обход через публичные посторонние прокси не используется. Истёкшие ссылки с явным ответом 404/410 показывают понятную ошибку.

Blob-ссылка освобождается через 60 секунд, чтобы браузер успел начать сохранение, а не через прежнюю одну секунду. Токен Firebase отправляется только настроенному доверенному Worker. Проверка владельца/роли сохраняется.

Правила Firestore и Worker в этой правке не менялись. Платные генерации не выполнялись. Пересборка HTML, проверка синтаксиса и 9 тестов Assets/скачивания прошли. Браузерный сценарий расширен проверкой расположения кнопки и скачивания из ноды до предпросмотра, но здесь не запускался успешно из-за ограничений окружения.
