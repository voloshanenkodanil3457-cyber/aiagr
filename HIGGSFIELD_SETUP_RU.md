# Higgsfield в Canvas

BytePlus остаётся основным провайдером Seedance 2.5. Если он явно отклонил референс с лицом, в Output появляется переход на Higgsfield. В панели генерации с медиа также доступен ручной выбор Higgsfield.

Перед каждой отправкой открывается предупреждение о возможной повышенной стоимости. Только кнопка подтверждения создаёт новую платную задачу. Отмена ничего не запускает. Сетевая ошибка, нехватка баланса и другие ошибки не переключают провайдера автоматически. Higgsfield также проверяет референсы по своим правилам.

## Активация

1. Cloudflare → Workers & Pages → magic-higgsfield → Settings → Variables and Secrets → Add.
2. Выбрать Secret, имя HF_CREDENTIALS, значение в формате ID:SECRET. Ввести значение самостоятельно и сохранить через Deploy. Не публиковать его в чате или GitHub.
3. На сайте: My settings → Higgsfield → Проверить. Эта проверка не запускает генерацию и проверяет только доступность настройки.
4. Пополнить отдельный API-баланс Higgsfield перед использованием.

Адрес Worker уже задан в конфигурации сайта. Локальный .env.local предназначен только для примера index.ts и не передаёт ключ в Cloudflare. Worker развёрнут на существующем плане Free; действуют его квоты.

Точная цена Higgsfield в калькулятор не выдумывается: тариф BytePlus не применяется к этим задачам. Сверять цену следует с официальным API-прайсингом Higgsfield.

Проверки интерфейса и маршрутизации выполнены с заглушками. По просьбе владельца платные генерации для проверки интеграции сайта не запускались.
