# Сверка расходов Higgsfield

Cost разделяет сохранённые списания/сверенные суммы, предварительные оценки и неизвестную стоимость. Наличие неизвестных сумм делает итог неполным. Наличие оценки обозначается ≈, включая Dashboard, Assets и рейтинг пользователей.

Higgsfield: старое поле `cost` без подтверждённого источника Billing не доказывает фактическое списание. Публичный тариф и `/estimate` остаются оценками. Тариф не учитывает неизвестную скидку аккаунта. Не меняем суммы на основании общего расхода аккаунта.

Официальные источники проверены 24.10.2026:
- https://docs.higgsfield.ai/docs/concepts/billing-and-retention
- https://docs.higgsfield.ai/docs/how-to/sdk

Документирован endpoint оценки перед запуском; не найден документированный endpoint окончательного списания по ID старого запроса. Автоматическая сверка списаний не заявляется, платные генерации не используются для проверки.

## Командный журнал SuperAdmin

Cost → «Стоимость каждого видео» → Request ID → «Сверить с Billing». Ввести точную сумму в USD (включая 0 при подтверждённом возврате/бесплатной задаче) и номер операции/описание записи. После подтверждения сумма входит в командный учёт; показывается как ручная сверка SuperAdmin, а не ответ API.

Используются уже существующие права `config/{docId}`: журнал `config/videoBilling` читается и изменяется только superuser. Новые разрешения и публикация Firestore rules не нужны. Он применяется к командным отчётам и Assets/Dashboard SuperAdmin; личные отчёты обычных пользователей продолжают показывать сохранённые цены/оценки, что явно указано в Cost. Исходные записи videos и начисления рейтинга не изменяются.

Запись привязана к video ID, uid и requestId; отсутствующий ID блокирует ручную сверку. Транзакция сверяет текущую ревизию и фактическую завершённую запись Higgsfield, защищая от параллельных правок. Сохраняются автор, время, источник и последние 20 предыдущих редакций. Журнал ограничен 750 КБ с явной ошибкой при заполнении. Ошибка чтения журнала показывается отдельно; неподтверждённые суммы не выдаются за загруженную сверку.

Скриншот общего Billing не сопоставляет операции с отдельными генерациями. Значения $0.70 и $1.54 в продуктивную БД автоматически не внесены.
